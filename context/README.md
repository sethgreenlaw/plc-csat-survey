# Context

Domain knowledge and context for AI coding agents building OpenGov government software.

## Files

| File | Description |
|------|-------------|
| `personas.md` | Government user personas with tech fluency levels and design implications |
| `suite-scope.md` | OpenGov software suite descriptions (B&P, EAM, PLC, PRO, FIN) |

## Purpose

This context helps AI agents understand:

1. **Who uses the software** - Government employees with varying technical abilities
2. **What problems they solve** - Budgeting, asset management, permitting, procurement, financials
3. **How to design for them** - Appropriate complexity levels, mobile considerations

## Usage

When building features, consider:

- **User's tech fluency** - Low-tech users need simpler interfaces
- **Suite context** - Which product suite the feature belongs to
- **Integration points** - How data flows between systems
- **Domain terminology** - Use government-appropriate language

## Adding More Context

Add new markdown files to this directory for:

- Additional personas or user journeys
- Domain-specific terminology glossaries
- Workflow documentation
- Business rules and constraints
- Integration requirements
